# Family Tree Legacy

MASTER DEVELOPMENT PROMPT (ENHANCED VERSION)

Application & Website Name: MAGDALENE FOUNDATION

Tagline:
Sethare se segologolo, Sethare sa maungo a monate, Sethare se moriti o tsididi

---

1. OVERVIEW

Develop a family-centered digital platform ecosystem called Magdalene Foundation, designed to serve as living digital homes and institutional memories for extended families. The platform preserves genealogy, documents services and skills, centralizes shared resources, and strengthens intergenerational connection through intelligent systems and engagement tools.

The system must be:

· Easy to use for elders and youth
· Emotionally warm and respectful
· Secure, structured, and scalable
· Architected to host multiple independent family circles

---

2. CORE IDENTITY

· Name: Magdalene Foundation
· Tagline: Sethare se segologolo, Sethare sa maungo a monate, Sethare se moriti o tsididi
· Logo Concept: Active flat line (symbol of continuity and legacy)
· Theme: Light, soft shades of green
· Tone: Calm, dignified, family-first
· Platforms: Web (PWA with offline-first capability), Android, iOS

---

3. PLATFORM ARCHITECTURE

Multi-Family Structure

· The platform hosts multiple independent family "Circles"
· Each Circle has its own:
  · Family name(s) and configuration
  · Family tree structure
  · Member roster (approved by Circle Superusers)
  · Private resources, media, and data
· Data isolation is absolute between Circles

Circle Creation

· Founding Superuser creates a new "Magdalene Foundation Circle" for their family
· Configures initial surname(s), founding generation data
· Invites family members via email/SMS
· Each Circle is a self-contained digital family home

---

4. AUTHENTICATION & ACCESS CONTROL

Login

· Email + password authentication
· No public access - invitation or approval required
· All users must be approved by their Circle's Superusers
· Demo mode available (read-only generic family data)

Family Circle & Profile Claiming

Onboarding Flow:

1. User receives invitation to join "[Family Name] Circle"
2. Accepts invitation, creates account
3. "Claim Your Profile" Process:
   · Searches for their name in existing family tree
   · If found: Requests to claim profile → Superuser notified for verification
   · If not found: "Request Addition" → Superuser creates node and links profile
4. For minors: Parents/guardians can create and manage Guardian-linked profiles

---

5. PROFILE SYSTEM (ENHANCED)

Demographic + Capability Profile

Each profile contains:

· Full name (verified against family tree)
· Gender
· Date of birth / age (calculates generation automatically)
· Generation label (auto-assigned based on tree position)
· Mobile number (private by default)
· Current location
· Occupation
· Short bio (optional)
· Guardian assignment for minors (<18)

Services & Skills (Enhanced)

· Users list services/skills they offer (plumbing, catering, teaching, etc.)
· New features:
  · Simple availability indicator ("Available for family requests")
  · "Thank You" endorsement system (family members can give thanks)
  · Service history (optional, user can show past family help provided)
· Services are automatically indexed in Family Resources → Services Directory

Inter-Family Linkage

· Marriage/Partnership links between nodes in different family trees
· Maintains separate family identities while acknowledging connections
· Bi-directional relationship awareness

6. USER ROLES & GOVERNANCE

Superusers (Circle Administrators)

· Mandatory 2FA for all Superusers
· Minimum of 2 Superusers required per Circle
· Succession Protocol: Designate successor Superusers
· Permissions:
  · Approve/deny users and profile claims
  · Edit and correct family tree structure
  · Manage all Circle content (announcements, resources, polls, games)
  · Moderate services and sensitive information
  · Upload official documents and media
  · Approve user-submitted recipes/stories
  · Export Circle data (full archive capability)

Regular Users

· Read-only access to family tree structure
· Update personal profile details (non-structural)
· Participate in games, polls, engagement features
· Submit recipes/stories to pending queue
· Give "Thank You" endorsements for services

Family Ambassadors (Optional Role)

· Tech-savvy members who assist elders with onboarding
· Designated by Superusers
· Limited admin capabilities for helping others

15. MAGGIE – ENHANCED AI ASSISTANT

Full Name & Identity

MAGGIE
Matriarchal Archive of Generational Genealogy & Insight Engine

Core Role

MAGGIE is the digital matriarch and intelligence core of each Family Circle, with access only to that Circle's data.

Enhanced Capabilities

1. Kinship Intelligence Engine

· "MAGGIE, how am I related to Uncle John?" → Shows relationship path
· "Find all my second cousins in Johannesburg" → List with contact options
· Proactive connections: "You and Sarah are both in Nairobi. Would you like to connect?"

2. Memory & Story Curator

· "MAGGIE, find all photos and stories from our 2010 reunion"
· "Show me everything about Grandmother's childhood"
· Gaps identification: "We have few stories from the 1980s. Would anyone like to share?"

3. Conflict-Sensitive Communications

· Anonymous confirmation workflow:
  ```
  MAGGIE: "I have unverified news about [Person]. 
  Should I notify the family? [Yes/No/Get Verification]"
  ```
· Gradual notification for sensitive news
· Check-in prompts after difficult events

4. Service & Resource Matchmaker

· "MAGGIE, we need a lawyer for property advice"
· "Find someone who can help with tutoring in math"
· Facilitates introductions with permission

5. Proactive Family Care

· Birthday reminders (with memory prompts)
· Anniversary acknowledgments
· "Family health" insights (engagement levels, story gaps)

Tone & Rules

· English only for clarity
· No proverbs or guessing - factual only
· Calm, respectful, elder-like voice
· Transparent about data sources: "According to the family tree..."
· Never shares data outside the Circle
